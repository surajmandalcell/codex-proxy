Security by architecture

Your keys stay behind the desktop boundary.

The renderer receives redacted snapshots, not credentials. Secrets are encrypted through the operating system when available, IPC senders are validated, and the server binds to loopback by default.

Exact-origin CORSNo permissive wildcard browser access.
Redacted loggingCredential-shaped fields never enter request logs.
Explicit trustExternal modules and commands are local, opt-in capabilities.
