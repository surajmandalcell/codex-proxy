Run multiple AI providers behind one local desktop gateway.

Subscription Proxy Inator exposes OpenAI- and Anthropic-compatible local routes, selects from configured provider accounts, records usage, and keeps credentials in the desktop main process.

01

Implemented capabilities

No hosted control plane is required. Configuration, routing state, credentials, and usage data remain local.

01

Providers and accounts

Multiple accounts per provider with independent priority, weight, enabled state, cooldown, and local limits.

02

Protocol compatibility

OpenAI Chat Completions, OpenAI Responses, Anthropic Messages, model discovery, token estimation, and health routes.

03

Failover

Rate limits, overloads, network errors, and timeouts can move to another eligible account before client-visible output starts.

04

Usage accounting

Input, output, cache read, cache write, latency, first-token latency, estimated cost, and route attempts.

03

Routing and failure handling

One global strategy is used by default. Each provider can override it, and one control removes all overrides.

  1. 01Priority
  2. 02Round robin
  3. 03Weighted random
  4. 04Least in-flight
  5. 05Lowest recent latency
  6. 06Lowest estimated cost
  7. 07Sticky session

Eligibility

Provider enabled state, account enabled state, model globs, local limits, cooldown, and attention state.

Temporary isolation

Retry-After and exponential cooldowns exclude routes after rate limits and transient failures.

Streaming boundary

A request never switches providers after text or a tool call becomes visible to the client.

05

Security boundaries

Security controls are enforced in the Electron main process and local HTTP server.

Credential storage

Electron safeStorage is used when available, with AES-256-GCM fallback encryption.

Renderer isolation

Context isolation and sandboxing are enabled; Node integration is disabled.

Network scope

The server rejects non-loopback bind addresses and uses exact-origin CORS.

Logging

Credential-shaped fields and bearer values are redacted before logs are stored or shown.
